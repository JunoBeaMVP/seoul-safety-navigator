# 서울 안전 길잡이 연동·운영 메모

## 데이터 원천과 역할

| 데이터 | 서버 연동 | 앱 내 역할 |
| --- | --- | --- |
| 기상청 초단기실황 | 공공데이터포털 `VilageFcstInfoService_2.0/getUltraSrtNcst` | 현재 기온·강수량·습도 표기와 보조 위험 신호 |
| 기상청 특보 | 공공데이터포털 `WthrWrnInfoService/getWthrWrnList` | 폭염·호우의 공식 주의보·경보 감지 |
| 서울시 무더위쉼터 | `OA-21065` / `TbGtnHwcwP` | 폭염 상황의 우선 대피시설 |
| 서울시 수해대피소 | `OA-21181` / `TL_FLOOD_P.xlsx` | 호우·침수 상황의 우선 대피시설 |
| 서울시 민방위대피시설 | `LOCALDATA_114602` | 민방위 상황의 우선 대피시설 |
| OpenRouteService | `foot-walking/geojson` | 선택 대피소까지의 도보 거리·예상 시간·경로선 |

서울시 수해대피소의 `XCORD`·`YCORD`은 WGS84 경도·위도이며, 현재 민방위 응답의 `XCRD`·`YCRD`은 각각 위도·경도로 관측됩니다. 구현은 이 실제 응답 형태를 우선 처리하고, 제공 문서상의 EPSG:5174·EPSG:5186 좌표도 변환할 수 있게 보완되어 있습니다.

## 비밀값 관리

다음 값은 **서버 환경변수**여야 하며, `client/` 코드나 `VITE_` 접두사의 변수에 넣으면 안 됩니다.

| 환경변수 | 용도 |
| --- | --- |
| `KMA_SERVICE_KEY` | 기상청 초단기실황·특보 조회 |
| `SEOUL_OPEN_API_KEY` | 서울시 무더위쉼터·민방위대피시설 조회 |
| `OPENROUTE_SERVICE_KEY` | OpenRouteService 도보 경로 조회 |

`server/safety.credentials.test.ts`는 각 키로 최소 외부 요청을 실행하며, 응답의 실제 데이터 형식까지 검증합니다. 테스트 출력에 키 자체를 기록하지 않습니다.

## 위험 판단과 안내 원칙

기상청의 **공식 호우·폭염 특보**를 최우선으로 판단하고, 강수량 또는 33°C 이상의 관측 온도는 특보가 없을 때의 보조 안전 안내로만 사용합니다. 호우 특보는 폭염 보조 신호보다 우선순위가 높습니다. 대피소 정렬은 우선 직선거리 기준이며, 사용자가 대상을 선택하면 OpenRouteService 도보 경로로 실제 거리·예상 시간을 별도 계산합니다.

> 이 서비스는 참고용 길잡이입니다. 대피 여부와 이동 경로는 재난문자, 119·112, 현장 통제, 대피시설 운영 상태를 우선합니다.

## 배포 후 주기 갱신 활성화

`/api/scheduled/weather-refresh` 콜백은 구현되어 있으나, 주기 작업은 배포된 서비스에만 생성할 수 있습니다. 배포 뒤 프로젝트 소유자 권한으로 3분 또는 5분 간격의 Heartbeat를 이 경로에 등록합니다. 콜백은 인증된 예약 호출만 허용하고, 같은 요청이 재시도되더라도 최신 스냅샷을 덮어쓰는 방식으로 동작합니다.

```text
권장 예시: 0 */3 * * * *  →  /api/scheduled/weather-refresh
```

스케줄 표현식은 UTC 기준 6필드입니다. 운영 정책상 요청량·기상청 호출 한도를 확인한 뒤 간격을 조정해야 합니다.

## 현 구현 검증 기록

2026-08-15에 서버 비밀값을 사용한 기상청 실황, 서울시 무더위쉼터·수해대피소·민방위대피시설, OpenRouteService 도보 경로의 경량 연결 검증을 통과했습니다. 또한 데스크톱(1280px)과 모바일(390px) 화면에서 실제 기상 수치, 12개 인근 무더위쉼터, OpenStreetMap 출처 표기를 확인했습니다.
